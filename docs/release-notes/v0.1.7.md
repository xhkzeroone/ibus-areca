## ibus-areca v0.1.7

### Tính năng mới
- **Mở cài đặt Areca từ GNOME Settings.** Trong Settings → Keyboard → Input Sources, bấm dấu ba chấm của "Vietnamese (Areca)" rồi chọn Preferences sẽ mở app cài đặt Areca. Sau khi cập nhật, chạy `ibus restart` hoặc đăng xuất rồi đăng nhập lại để GNOME nhận thay đổi.
